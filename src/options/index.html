Google 免费通道的翻译接口地址；被限流或不可用时可换备用端点。

主端点失败（限流 / 不可达）时自动切换的第二个免费端点。

逐行：一次请求多段、按行返回，兼容性最好。哨兵：用 ===IT_SEP=== 分隔输入输出，段落内含换行时更可靠，但对模型指令服从度要求高；解析失败会自动回退逐行。

温度：越低译文越稳定准确（默认 0.3）。并发：同时发出的 API 请求数，越大翻译越快，但更易触发限流（默认 6）。

备用 API（可选，主 API 失败时自动切换）

翻译设置

关闭时需点击页面右下角红点 → 「翻译」手动触发。

仅整页翻译携带；划词 / 输入框翻译不携带，避免额外 token。部分 API 有 token 上限时可关闭。

正文摘要的最大长度（标题/描述另有固定上限）。设得越小越省 token。

开启后，URL 含 login / password / 2fa / pay 等关键词的页面整页不翻译（输入框内的密码值本就永不翻译）。 关闭则所有页面都翻译。默认关闭。
