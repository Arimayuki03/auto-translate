API 服务

配置翻译用的 AI 通道；主通道失败时可自动切换备用通道。

主通道

只需填到域名 / 版本层级，插件会自动拼接接口路径。

仅保存在本机浏览器存储（落盘前做混淆处理）。

Google 免费通道的翻译接口地址；被限流或不可用时可换备用端点。

主端点失败（限流 / 不可达）时自动切换的第二个免费端点。

逐行：一次请求多段、按行返回，兼容性最好。哨兵：用 ===IT_SEP=== 分隔输入输出，段落内含换行时更可靠，但对模型指令服从度要求高；解析失败会自动回退逐行。

非空时作为「附加指令」拼在系统提示词最前面。批量协议的分段 / 逐行指令始终完整保留在附加指令之后，不会被覆盖；免费通道不使用该指令。最长 2000 字符。

请求控制

温度：越低译文越稳定准确（默认 0.3）。并发：同时发出的 API 请求数（默认 2）。请求间隔：相邻请求的最小启动间隔（默认 500 毫秒，≈2 请求/秒）——中转站/服务商限额严格时调大，如 1000～2000。

备用通道 可选

主 API 失败（限流 / 不可达）时自动切换。留空即不启用。

翻译行为

控制何时翻译、翻译哪些内容，以及译文的呈现方式。

触发方式

打开网页时自动翻译 仅当前前台标签页；关闭时需点击页面右下角红点 → 「翻译」手动触发。
视口懒翻译 只翻译当前浏览区域，滚动到附近才译新内容，节省额度。
划词翻译 选中文本自动弹出译文气泡。
输入框翻译 输入框右上方显示「译」按钮。
悬停翻译 悬停段落左上角显示「译」角标，点击只译该段。
翻译 HTML 属性 输入框 placeholder、链接 title、图片 alt、aria-label。

上下文理解

整页翻译携带页面上下文 携带标题/描述/正文摘要帮助模型理解语境；划词 / 输入框翻译不携带。部分 API 有 token 上限时可关闭。
LLM 页面摘要 请 AI 概括长文主题注入上下文，专业长文的翻译更贴语境；每页至多多一次请求（结果已缓存）。免费通道不支持，自动跳过。

正文摘要的最大长度（标题/描述另有固定上限）。设得越小越省 token。

页面正文超过该字数才生成 LLM 摘要；0 = 长短页都生成。

译文样式

面向 .it-translated（译文块）等类名书写，最长 8000 字符；保存后刷新页面生效。

页面语言被端点误判时手动指定；LLM 通道注入提示词，免费通道作为 sl/from 参数。

划词朗读（TTS）

在划词气泡中朗读译文，使用 Edge TTS 免费合成，无需 API Key。

启用朗读按钮 在划词翻译气泡中显示「朗读」按钮；朗读时点击可停止，关闭气泡也会停止。

自动模式按当前目标语言挑选声音；手动指定后始终使用所选声音。

站点管理

控制哪些站点翻译、哪些排除，并为常见站点启用内置适配规则。

黑白名单

仅这些站点自动翻译；留空则全部站点。

这些站点永不翻译，优先级高于白名单。

敏感页面不翻译 URL 含 login / password / 2fa / pay 等关键词的页面整页跳过（输入框内的密码值本就永不翻译）。默认关闭。

站点规则库

常见站点的「排除区」适配：导航 / 按钮 / 字幕 / 代码区等不翻译。取消勾选即禁用；保存后刷新页面生效。

matches 支持域名通配（*.example.com / www.amazon.*）与路径前缀（example.com/docs）。 可选字段：excludeSelectors（命中元素及其子树不翻译）、excludeTags（不翻译的标签）、 forceBlockTags（强制按块级翻译单元处理的标签）、excludeMatches（反排除）、enabled。 与命中的内置规则合并生效；保存后刷新页面生效。
