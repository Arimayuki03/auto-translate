# 测试计划

> 覆盖功能、兼容性、性能与验收标准。每阶段开发完成后按此清单验证。

## 1. 测试环境

- Chrome 110+（最新稳定版）/ Edge 110+
- 测试页面：英文新闻站（BBC）、技术文档（MDN/GitHub README）、SPA（GitHub Issues、YouTube）、中文站（回归用）
- 自建 API：本地 vLLM 或任意 OpenAI 兼容服务

## 2. 功能测试用例

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| T-001 | 整页自动翻译 | 打开英文页面 | 页面出现双语对照，原文保留、译文高亮在下 |
| T-002 | 模式切换 | 工具条切换"仅译文/原文" | 对应模式生效，可一键还原 |
| T-003 | 段落翻译 | 悬停段落点"翻译" | 仅该段落出现译文 |
| T-004 | 划词翻译 | 选中文本 | 弹出气泡显示译文，可复制/关闭 |
| T-005 | 输入框翻译 | 输入框输入内容点"翻译" | 译文回填输入框 |
| T-006 | API 配置 | 填错 Key / BaseURL | 测试连接给出明确错误提示 |
| T-007 | 缓存命中 | 翻译同一页面两次 | 第二次无 API 请求（Network 面板验证） |
| T-008 | 黑名单 | 域名加入黑名单后刷新 | 页面不翻译 |
| T-009 | 动态内容 | SPA 路由切换/评论区加载 | 新增内容自动翻译 |
| T-010 | 异常恢复 | 停用 API 后刷新页面 | 译文块显示错误状态，页面不崩溃 |
| T-011 | 长文分块 | 翻译超长文章 | 译文完整、顺序正确 |
| T-012 | 还原 | 翻译后点还原 | 页面恢复原始 DOM，无残留标记 |

## 3. 兼容性测试

| 场景 | 检查项 |
| --- | --- |
| iframe / 嵌套页面 | 不翻译 iframe 内容，不影响主页面 |
| 代码块 / 公式 | `pre`、`code`、`math` 等内容不被翻译 |
| 表单 / 输入框 | 原文不被错误替换，输入框翻译按钮正常 |
| 深色站点 | 译文块样式可读 |
| 多语言页面 | 目标语言切换后译文正确 |

## 4. 性能测试

- 单页 ≥200 个文本块：首屏 3 秒内出现首批译文
- 页面滚动流畅：翻译过程不阻塞滚动（如有卡顿，启用视口懒翻译）
- 缓存生效后重复翻译零网络请求

## 5. 验收标准（M2 核心可用）

- [ ] T-001 / T-002 / T-006 / T-007 全部通过
- [ ] 连续翻译 10 个不同页面无崩溃、无错位
- [ ] 页面还原后无插件残留 DOM
