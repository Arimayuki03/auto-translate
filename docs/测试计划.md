# 测试计划

> 覆盖功能、兼容性、性能与验收标准。每阶段开发完成后按此清单验证。

## 1. 测试环境

- Chrome 109+（manifest 声明 `minimum_chrome_version: 109`——offscreen API 自 109 起可用）/ Edge 109+
- 测试页面：英文新闻站（BBC）、技术文档（MDN/GitHub README）、SPA（GitHub Issues、YouTube）、中文站（回归用）
- 自建 API：本地 vLLM 或任意 OpenAI 兼容服务

## 1.1 自动化测试与 CI

- `npm test`（vitest）：单元/回归/e2e 一体，e2eSmoke 4 例用 Playwright 加载真实扩展（有 Chromium 且
  dist/ 存在才运行，否则在报告中显式 skipped；`SKIP_E2E=1` 可强制跳过）
- `npm run typecheck`：双 tsconfig project（src 保持 chrome 类型、tests 另用 node 类型）
- CI（.github/workflows/build.yml）：npm ci → typecheck → lint → build → install playwright chromium
  → test → package zip → upload artifact；e2e 在 CI 为真实运行
- 打包：`npm run zip`（zip.mjs，fflate 纯 JS 压缩，条目路径恒为正斜杠；版本号非法或 dist 早于源码时拒绝打包）

## 2. 功能测试用例

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| T-001 | 整页自动翻译 | 打开英文页面 | 页面出现双语对照，原文保留、译文灰字在下 |

| T-007 | 缓存命中 | 翻译同一页面两次 | 第二次无 API 请求（Network 面板验证） |
| T-008 | 黑名单 | 域名加入黑名单后刷新 | 页面不翻译 |

| T-011 | 长文分块 | 翻译超长文章 | 译文完整、顺序正确 |
| T-012 | 还原 | 翻译后点还原 | 页面恢复原始 DOM，无残留标记 |

## 3. 兼容性测试

| 场景 | 检查项 |
| --- | --- |
| iframe / 嵌套页面 | 不翻译 iframe 内容，不影响主页面 |
| 代码块 / 公式 | `pre`、`code`、`math` 等内容不被翻译 |
| 表单 / 输入框 | 原文不被错误替换，输入框翻译按钮正常 |
| 深色站点 | 译文块样式可读 |
| 多语言页面 | 目标语言切换后译文正确 |

## 4. 性能测试

- 单页 ≥200 个文本块：首屏 3 秒内出现首批译文
- 页面滚动流畅：翻译过程不阻塞滚动（如有卡顿，启用视口懒翻译）
- 缓存生效后重复翻译零网络请求
