# 开发计划

> 分阶段开发清单，每完成一项勾选 `[x]`。

## 阶段 1：工程骨架

- [ ] 初始化 Vite + TypeScript + @crxjs/vite-plugin 工程
- [ ] 编写 `manifest.json`（MV3，声明权限：storage、activeTab、scripting）
- [ ] 添加占位图标（16/32/48/128）
- [ ] 扩展可在 Chrome 开发者模式加载
- [ ] 配置 Git 提交规范与 `.gitignore`（已完成）

- [ ] 设计适配器接口：统一请求 / 响应 / 错误映射

- [ ] 实现 Google Gemini 适配器（`providers/gemini.ts`）

- [ ] 实现并发控制与批量合并（`src/background/queue.ts`）
- [ ] 实现缓存（`src/background/cache.ts`，键：语言+原文哈希）
- [ ] 实现错误分级与重试

## 阶段 3：全文翻译（MVP）

- [ ] 文本节点提取与过滤（`src/content/extractor.ts`）

- [ ] 三种显示模式（双语 / 仅译文 / 原文）与一键还原
- [ ] 翻译中占位动画、逐块替换
