# 使用说明

## 1. 安装插件

1. 构建项目（开发者环境）：`npm install && npm run dev`，或使用已打包的 `dist/` / zip
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 右上角打开 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择项目 `dist/` 目录
5. 确认工具栏出现插件图标

## 2. 配置 AI API（第一次使用必做）

1. 点击插件图标 → **设置**（或右键图标 → 选项）
2. 在"API 配置"填写：
   - **BaseURL**：如 `https://api.deepseek.com/v1`
   - **API Key**：你的密钥
   - **模型**：如 `deepseek-chat`
3. 点击 **测试连接**，看到"连接成功"即配置完成

## 3. 日常使用

### 整页翻译
- 打开任意外语网页，插件默认自动翻译（可在设置中关闭自动翻译）
- 页面顶部悬浮工具条：切换 **双语 / 仅译文 / 原文** 模式，点击 **还原** 恢复页面

### 划词翻译
- 选中一段文字，松开鼠标后自动弹出译文气泡
- 气泡上可复制译文；点关闭按钮收起

### 输入框翻译
- 在输入框 / 文本框输入内容后，输入框下方出现"翻译"按钮
- 点击后将译文回填到输入框（可在设置中关闭）

### 段落翻译
- 将鼠标悬停在段落上，段落右侧出现"翻译"按钮，点击仅翻译该段落

## 4. 设置项说明

| 设置 | 说明 |
| --- | --- |
| 目标语言 | 译文语言，默认中文 |
| 自动翻译 | 打开页面是否自动翻译，默认开 |
| 显示模式 | 双语对照 / 仅译文 / 原文 |
| 最短文本长度 | 低于该长度的文本不翻译（默认 4 字符） |
| 黑名单 | 这些域名不自动翻译 |
| 缓存 | 开启后重复内容直接返回缓存译文；可一键清空 |

## 5. 常见问题

- **译文一直是"翻译中"**：检查 API 配置（测试连接），或看 API 服务日志
- **部分段落没翻译**：可能文本过短被过滤，或该标签被排除（代码块、表单等）
- **译文错位**：点击"还原"后重新翻译
- **想停用翻译**：点击插件图标关闭开关，或把当前域名加入黑名单
