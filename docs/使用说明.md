# 使用说明

## 1. 安装插件

1. 构建项目（开发者环境）：`npm install && npm run dev`，或使用已打包的 `dist/` / zip
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 右上角打开 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择项目 `dist/` 目录
5. 确认工具栏出现插件图标

## 2. 配置 AI API（第一次使用必做）

1. 点击插件图标 → **设置**（或右键图标 → 选项）
2. 在"API 配置"填写：
   - **BaseURL**：如 `https://api.deepseek.com/v1`
   - **API Key**：你的密钥
   - **模型**：如 `deepseek-chat`
3. 点击 **测试连接**，看到"连接成功"即配置完成

## 3. 日常使用

### 整页翻译
- 打开任意外语网页，点击页面右下角**红色小圆圈** → 面板中点「翻译」；或在设置里开启「自动翻译」（打开页面自动译当前屏）
- 面板可切换 **双语 / 仅译文 / 原文** 模式、目标语言，点「还原」恢复页面
- 默认只翻译当前视口内容（视口懒翻译），滚动到附近才译新内容，节省额度

### 划词翻译
- 选中一段文字，松开鼠标后自动弹出译文气泡
- 气泡上可复制译文；点关闭按钮收起

### 输入框翻译
- 在输入框 / 文本框输入内容后，输入框右上方出现「译」按钮
- 点击后将译文回填到输入框（可在设置中关闭输入框翻译）

### 快捷键
- `Alt+T` 翻译 / 还原当前页；`Alt+M` 轮换显示模式

## 4. 设置项说明

| 设置 | 说明 |
| --- | --- |
| API 配置 | 格式 / BaseURL / Key / 模型 / 温度 / 超时 / 最大并发 |
| 自动翻译 | 打开页面是否自动翻译当前屏，默认关（手动：点红点 → 翻译） |
| 视口懒翻译 | 只翻译当前浏览区域，滚动到附近才译新内容，默认开 |
| 白名单 | 填了域名后仅这些站点自动翻译（省额度）；留空 = 全部站点 |
| 黑名单 | 这些域名永不自动翻译，优先级高于白名单 |
| 缓存 | 译文缓存跨会话复用（节省额度）；设置页可一键清空 |

> 目标语言、显示模式（双语/仅译文/原文）在页面的红点面板里切换，不在设置页。

## 5. 常见问题

- **译文一直是"翻译中"**：检查 API 配置（测试连接），或看 API 服务日志
- **部分段落没翻译**：可能文本过短被过滤，或该标签被排除（代码块、表单、按钮等）
- **译文错位**：点击"还原"后重新翻译
- **想停用翻译**：点页面红点 → 还原；或把当前域名加入黑名单
- **怎么省翻译额度**：把常看的站点加入白名单，白名单外的页面不会自动翻译
