# 使用说明

## 1. 安装插件

1. 构建项目（开发者环境）：`npm install && npm run dev`，或使用已打包的 `dist/` / zip
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 右上角打开 **开发者模式**
4. 点击 **加载已解压的扩展程序**，选择项目 `dist/` 目录
5. 确认工具栏出现插件图标

## 2. 配置 AI API（第一次使用必做）

**方式 A：不想申请 Key？用免费通道（开箱即用）**

1. 点击插件图标 → **设置**（或右键图标 → 选项）
2. 「API 格式」选 **Google 免费（无需 Key）** 或 **Microsoft 免费（无需 Key）**，直接保存即可
3. 免费有频率限制，可作为主力或兜底；Google 免费通道可在设置里填自定义主/备端点
4. 两个免费通道互为备份：主通道被限流/不可达时（未配置备用 API 的前提下）自动切到另一个

**方式 B：使用自己的 AI API**

1. 点击插件图标 → **设置**（或右键图标 → 选项）
2. 在"API 配置"填写：
   - **BaseURL**：如 `https://api.deepseek.com/v1`
   - **API Key**：你的密钥
   - **模型**：如 `deepseek-chat`
3. 点击 **测试连接**，看到"连接成功"即配置完成
4. （可选）配置**备用 API**：主 API 失败时自动切换；也可填免费通道作备用兜底

## 3. 日常使用

### 整页翻译
- 打开任意外语网页，点击页面右侧**红色小圆圈** → 面板中点「翻译」；或在设置里开启「自动翻译」（打开页面自动译当前屏）
- 面板：**翻译 / 还原** 开关 + 显示模式（**双语对照 / 仅译文**）+ 目标语言选择
- 点「还原」恢复原文；显示模式也可用快捷键 `Alt+M` 轮换
- 默认只翻译当前视口内容（视口懒翻译），滚动到附近才译新内容，节省额度

### 划词翻译
- 选中一段文字，松开鼠标后自动弹出译文气泡
- 气泡上可**复制**译文，或点**朗读**听译文发音（Edge TTS 免费合成，无需 Key）；朗读中按钮变「停止」可随时停，关闭气泡也会停止
- 点关闭按钮收起

### 输入框翻译
- 在输入框 / 文本框输入内容后，输入框右上方出现「译」按钮
- 点击后将译文回填到输入框

### 快捷键
- `Alt+T` 翻译 / 还原当前页；`Alt+M` 轮换显示模式

### 插件总开关
- 点击工具栏插件图标，弹窗最顶部有**插件开关**
- 关闭：已翻译的页面立即还原为原文，悬浮工具条收起，整页翻译 / 划词 / 输入框 / 悬停 / 快捷键全部停用（无需刷新，所有已打开标签页即时生效）
- 重新开启：功能入口恢复；若设置里开着「自动翻译」，当前页会自动重新翻译
- 开关只是停用功能，不会清空任何已保存的 API 配置

## 4. 设置项说明

| 设置 | 说明 |
| --- | --- |
| API 配置 | 格式（OpenAI 兼容 / Claude / Gemini / Ollama / Google 免费 / Microsoft 免费）/ BaseURL / Key / 模型 / 温度 / 超时 / 最大并发 |
| 请求间隔（毫秒） | 相邻请求的最小启动间隔，默认 500（≈2 请求/秒）；中转站 / 服务商限额严格时调大，如 1000～2000 |
| 批量协议 | 逐行（默认，兼容性最好）/ 哨兵 `===IT_SEP===`（段落含换行时更可靠）；两个免费通道固定用哨兵，无需关心 |
| 上下文感知 | 整页翻译时附带页面标题/描述/正文摘要帮助模型理解语境，默认开；可限制摘要长度 |
| 译文样式 | 灰字（默认）/ 描边（空心字）/ 虚线下划线 / 模糊（悬停显形）；保存后刷新页面生效 |
| 自定义译文 CSS | 叠加在主题之上的自定义样式（面向 `.it-translated` 等类名），最长 8000 字符；保存后刷新页面生效 |
| HTML 属性翻译 | 翻译输入框 placeholder、链接 title、图片 alt、aria-label，默认开 |
| 自动翻译 | 打开页面是否自动翻译当前屏，默认关（手动：点红点 → 翻译） |
| 视口懒翻译 | 只翻译当前浏览区域，滚动到附近才译新内容，默认开 |
| 划词翻译 | 选中文本自动弹出译文气泡，默认开 |
| 划词朗读（TTS） | 气泡「朗读」按钮，Edge TTS 免费合成（无需 Key）；声音默认按目标语言自动选（可指定），语速 0.5×~2× 可调 |
| 输入框翻译 | 输入框右上方显示「译」按钮，默认开 |
| 白名单 | 填了域名后仅这些站点自动翻译（省额度）；留空 = 全部站点 |
| 黑名单 | 这些域名永不自动翻译，优先级高于白名单 |
| 缓存 | 译文缓存跨会话复用（节省额度）；默认保留 7 天（可改，0 = 永不过期），每天自动清理一次；设置页可看条目数、立即清理或一键清空 |
| 复制诊断信息 | 翻译失败时工具条出现「复制诊断信息」按钮（脱敏，不含 Key），便于反馈问题 |

> 目标语言在页面红点面板切换；显示模式（双语/仅译文）在面板选择，原文用「还原」恢复。

## 5. 常见问题

- **译文一直是"翻译中"（灰色呼吸块）**：翻译等待期会显示骨架屏占位；长时间不变，点工具条「复制诊断信息」查看具体失败原因（如「主 API 鉴权失败」）
- **部分段落没翻译**：可能文本过短被过滤，或该标签被排除（代码块、表单、按钮等）
- **频繁触发限流（429）**：把设置里的「请求间隔（毫秒）」调大（如 1000～2000）；「最大并发」保持 2 或更低；免费通道之间会自动互切，也可把另一个免费通道设为备用 API
- **译文错位 / 页面跳动**：点击"还原"后重新翻译
- **想停用翻译**：点页面红点 → 还原；或把当前域名加入黑名单
- **怎么省翻译额度**：把常看的站点加入白名单，白名单外的页面不会自动翻译；译文缓存会自动复用已翻译内容（同一站点开多个标签页也只会请求一次）
- **译文样式想换一种**：设置页「译文样式」选描边 / 虚线下划线 / 模糊，或写自定义 CSS，保存后刷新页面生效
