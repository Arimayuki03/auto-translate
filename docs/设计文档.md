# 沉浸式网页翻译浏览器插件 — 设计文档

> 仿照沉浸式翻译（Immersive Translate），使用自建 AI API（OpenAI 兼容接口）实现网页双语翻译。

## 1. 项目概述

一个基于 **Manifest V3** 的 Chromium 浏览器扩展，在浏览网页时自动将页面内容翻译为目标语言，并默认采用"双语对照"模式（原文保留，译文高亮显示在其下方），支持整页翻译、划词翻译、输入框翻译等能力。

### 核心目标
- 网页全文翻译（段落级双语对照 / 仅译文 / 原文模式）
- 划词翻译（选中文本后弹出小窗显示译文）
- 输入框翻译（在搜索框 / 输入框中快捷翻译已输入内容）
- 页面内局部翻译（每个段落旁显示"翻译"按钮，可单独翻译）
- 自定义 AI API：用户自备 BaseURL / API Key / 模型名称
- 译文缓存，避免重复请求，节省 API 费用

## 2. 技术选型

| 项 | 选择 | 说明 |
| --- | --- | --- |
| 浏览器 | Chrome / Edge（Chromium） | 先做 Chrome，兼容 Edge |
| 扩展规范 | Manifest V3 | 当前 Chrome 主流规范，Service Worker 替代 Background Page |
| 语言 | TypeScript | 类型安全，利于 DOM 处理与消息通信 |
| 构建 | Vite + @crxjs/vite-plugin | 热更新、自动打包 zip |
| 样式 | 原生 CSS + 自定义属性（CSS Variables） | 轻量，主题切换方便 |
| 状态存储 | chrome.storage.local（设置）+ chrome.storage.session（缓存） | 设置持久化，缓存会话级 |
| AI 协议 | OpenAI 兼容 `chat/completions` | 对接绝大多数自建 API（OneAPI、new-api、vLLM、Ollama 等） |

## 3. 功能需求

### 3.1 页面全文翻译（核心）
- 自动识别网页正文，按段落（p、li、h1-h6、blockquote 等）切块
- 翻译前先渲染"译文占位"（加载动画），翻译完成后替换为译文
- 三种显示模式：
  - 双语对照（默认）：原文下方插入译文块，译文高亮
  - 仅译文：隐藏原文，译文替换显示
  - 原文模式：一键恢复原始页面
- 页面顶部悬浮工具条：模式切换、目标语言、翻译/还原、设置入口
- 对已翻译内容不重复翻译（通过 DOM 标记 `data-it-translated`）

### 3.2 划词翻译
- 监听 `mouseup`，选中文本后弹出气泡卡片显示译文
- 支持快捷键（如双击 Alt / 自定义按键）触发
- 气泡可固定、可复制、可发音（TTS，后续迭代）

### 3.3 输入框翻译
- 在 `input` / `textarea` 内容可编辑区域提供翻译按钮
- 将输入内容翻译后替换或插入到输入框，便于跨语言交流

### 3.4 PDF 翻译（后续迭代）
- 优先使用浏览器内置 PDF 阅读器，将文本层映射到内容脚本翻译
- 复杂版式不追求还原，保证文字可读

### 3.5 设置页（Options）
- API 配置：BaseURL、API Key、模型、温度、超时时间
- 翻译设置：目标语言、显示模式、自动翻译开关、翻译触发方式
- 站点黑名单：指定域名不自动翻译
- 缓存管理：查看/清空缓存
- 数据导出 / 导入（配置迁移）

### 模块职责
- **content script**：注入页面，负责 DOM 提取、译文渲染、交互（工具条/气泡/按钮）。页面上下文隔离，不直接发网络请求。
- **background service worker**：唯一网络出口。接收 content script 的翻译请求，负责限流、重试、缓存、批量合并请求，防止页面里同时发起大量请求打爆 API。
- **popup**：快速开关翻译、切换模式、进入设置。
- **options**：完整设置页，配置 API 与偏好。

### 消息协议（runtime messaging）
```ts
type TranslateRequest = {
  id: string;
  action: "translate";
  texts: string[];          // 批量文本（同一批次一起发）
  sourceLang?: string;
  targetLang: string;
  preserveFormat?: boolean;  // 是否保留原文标记（用于 HTML 片段翻译）
};

type TranslateResponse = {
  id: string;
  ok: boolean;
  results?: string[];        // 与 texts 一一对应
  error?: string;
};
```

## 5. 翻译引擎设计（content script 核心）

### 5.1 文本节点提取
- 使用 TreeWalker 遍历 DOM，收集**叶子文本节点**
- 过滤规则：
  - 跳过 `script`、`style`、`noscript`、`iframe`、`svg`、`code`、`pre` 等标签
  - 跳过空白文本（`text.trim().length === 0`）
  - 跳过已翻译标记（`data-it-translated`）
  - 跳过长度小于阈值（如 2 字符）的碎片文本，减少请求量
- 对相邻叶子节点做**块合并**：同段落内多个文本节点合并为一个翻译单元，保证句子完整

### 5.2 分块与句切分
- 单次翻译单元过长时按句子切分（正则匹配 `。！？.!?…` 等），每块控制在约 800–1500 字符
- 块之间建立映射表 `{ originalText → nodeRefs[] }`，译文回来按位置回填

### 5.3 双语渲染
- 对每个翻译单元，原文节点保持不动，在其后插入：
```html
<div class="it-translated" data-it-translated="true" lang="zh-CN">
  <span class="it-src">原文（可选）</span>
  <span class="it-dst">译文</span>
</div>
```
- 仅译文模式：隐藏原文（加 `display:none` 类），保留 DOM 以便一键还原
- 还原：移除所有 `.it-translated` 节点并恢复原文显示

### 5.4 渐进式渲染
- 页面加载后先给每个待译块挂"译文中…"占位，翻译完成逐块替换，避免长时间白屏
- 使用 `IntersectionObserver`：只翻译视口附近的块，滚动到哪译到哪（可选，默认全量）

### 5.5 与页面样式隔离
- 所有注入样式使用带前缀的类名（`.it-*`）并挂在 Shadow DOM 或带 `all: revert` 的隔离容器，避免污染站点样式

## 6. AI API 接入设计（background 核心）

### 6.1 请求格式（OpenAI 兼容）
```http
POST {baseURL}/chat/completions
Authorization: Bearer {apiKey}
Content-Type: application/json

{
  "model": "{model}",
  "messages": [
    { "role": "system", "content": "你是专业翻译引擎，将用户输入翻译为{目标语言}，只输出译文，不要解释。" },
    { "role": "user", "content": "请逐段翻译，段与段之间用 \n\n 分隔：\n\n{拼接后的原文}" }
  ],
  "temperature": 0.3,
  "stream": false
}
```

### 6.2 批量合并
- content script 同时提交的多个翻译单元在 background 合并为一次请求（用分隔符拼接，再按序拆分译文），大幅降低请求次数
- 单请求超限（如 4096 token）时自动降级为逐段请求

### 6.3 可靠性
- **限流**：信号量控制并发（默认 3），避免打爆自建 API
- **重试**：网络错误 / 5xx / 429 指数退避重试（最多 3 次）
- **超时**：默认 60s，AbortController 中断
- **错误分级**：网络错误可重试；4xx 认证错误直接提示用户检查 API 配置

### 6.4 缓存
- 缓存键：`md5(targetLang + "|" + normalizedText)`
- 会话级缓存 `chrome.storage.session`（MV3 下 session 存储无容量焦虑），命中即返回
- 设置页可一键清空缓存

## 7. 设置数据模型（chrome.storage.local）

```ts
interface Settings {
  api: {
    baseUrl: string;        // 如 https://api.openai.com/v1 或自建地址
    apiKey: string;         // 加密存储（chrome.storage + 简单混淆，或 optional_permissions 说明）
    model: string;          // 如 gpt-4o-mini / 自建模型名
    temperature: number;    // 默认 0.3
    timeoutMs: number;      // 默认 60000
    maxConcurrency: number; // 默认 3
  };
  translate: {
    targetLang: string;          // 默认 zh-CN
    displayMode: "bilingual" | "translated" | "original";
    autoTranslate: boolean;      // 默认 true
    minTextLength: number;       // 参与翻译的最短文本，默认 4
    blockMaxChars: number;       // 单块最大字符，默认 1200
    translateOnSelect: boolean;  // 划词翻译开关
    translateInput: boolean;     // 输入框翻译开关
  };
  blacklist: string[];           // 不自动翻译的域名
  cache: {
    enabled: boolean;            // 默认 true
    maxEntries: number;          // 默认 5000
  };
}
```

## 8. UI/UX 设计

- **顶部工具条**（页面内悬浮，可折叠）：翻译按钮、模式切换、语言选择、设置入口、还原

## 11. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 页面动态内容（SPA 路由切换） | MutationObserver 监听 DOM 变化，对新增节点按需翻译 |
| 长文分块导致上下文丢失 | 分块时保留前后文少量重叠；必要时用"翻译整个段落"提示 |
| 自建 API 并发/速率限制 | 限流 + 批量合并 + 指数退避 |
| 译文回填错位（原文被修改） | 回填前校验节点仍挂载且文本未变化，否则丢弃 |
| 样式冲突 | 类名前缀 + Shadow DOM 隔离 + CSS 变量主题 |
| API Key 泄露风险 | 仅存本地；README 提示自建 API 务必开鉴权 |
