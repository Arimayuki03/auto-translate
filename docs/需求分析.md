## 1. 项目目标

打造一款浏览器翻译插件，仿照沉浸式翻译的核心体验：在浏览外语网页时，以**双语对照**的方式展示译文，同时支持划词翻译、输入框翻译等快捷能力。翻译能力完全由用户**自建的 AI API** 提供，插件只负责文本提取、渲染与 API 调度。

## 2. 目标用户与使用场景

- 阅读英文/日文等技术文档、新闻、博客的用户
- 需要对照原文学习语言的用户（双语对照模式）
- 拥有自建 AI API（OneAPI / vLLM / Ollama / DeepSeek 等）且希望复用的开发者

## 4. 非功能需求

- **性能**：单页 200 段文本时，首屏 3 秒内开始出现译文；不阻塞页面滚动
- **兼容性**：Edge 110+ / Chrome 110+（主力浏览器为 Edge）；主流页面（新闻站、文档站、GitHub、YouTube 评论区）可用
- **安全**：API Key 仅保存在本地浏览器存储；不向任何第三方发送页面内容（仅发送到用户配置的 API 地址）
- **健壮性**：API 挂掉时不崩溃页面，译文块显示错误状态并可重试
- **无感体验**：自动翻译不弹提示、无闪烁、不改动滚动位置；译文平滑淡入，失败静默降级
